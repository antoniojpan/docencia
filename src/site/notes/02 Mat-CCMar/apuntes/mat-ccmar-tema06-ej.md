# Soluciones

> [!success] Solución del Ejercicio 1
> **(a)** $\displaystyle\int (6x^{2}+8x+3)\,dx = 2x^{3} + 4x^{2} + 3x + C.$
>
> **(b)** $\displaystyle\int (x^{3}+5)^{2}\,dx = \int (x^{6} + 10x^{3} + 25)\,dx = \frac{x^{7}}{7} + \frac{5x^{4}}{2} + 25x + C.$
>
> **(c)** $\displaystyle\int \frac{3}{2x+1}\,dx = \frac{3}{2}\ln|2x+1| + C.$
>
> **(d)** $\displaystyle\int \frac{x}{(x+1)^{2}}\,dx = \int \left(\frac{1}{x+1} - \frac{1}{(x+1)^{2}}\right)dx = \ln|x+1| + \frac{1}{x+1} + C.$
>
> **(e)** $\displaystyle\int \frac{x}{x^{2}+1}\,dx = \frac{1}{2}\ln(x^{2}+1) + C.$
>
> **(f)** $\displaystyle\int_{0}^{1} 4^{2-3x}\,dx = \left[-\frac{4^{2-3x}}{3\ln 4}\right]_{0}^{1} = \frac{16 - 1/4}{3\ln 4} = \frac{21}{8\ln 2}.$
>
> **(g)** $\displaystyle\int x e^{x^{2}+1}\,dx = \frac{1}{2}e^{x^{2}+1} + C.$
>
> **(h)** $\displaystyle\int \frac{e^{x}}{e^{x}-1}\,dx = \ln|e^{x}-1| + C.$
>
> **(i)** Por partes ($u=\arctan x$, $dv=dx$):
> $$\int \arctan x\,dx = x\arctan x - \int \frac{x}{x^{2}+1}\,dx = x\arctan x - \frac{1}{2}\ln(x^{2}+1) + C.$$
>
> **(j)** Por partes ($u=\ln x$, $dv=dx$):
> $$\int \ln x\,dx = x\ln x - \int 1\,dx = x\ln x - x + C.$$
>
> **(k)** Con la sustitución $u=\sqrt{x}$, $du = \frac{dx}{2\sqrt{x}}$:
> $$\int \frac{5^{\sqrt{x}}}{\sqrt{x}}\,dx = 2\int 5^{u}\,du = \frac{2\cdot 5^{\sqrt{x}}}{\ln 5} + C.$$
>
> **(l)** Con la sustitución $u=\ln x$, $du=\frac{dx}{x}$:
> $$\int_{1}^{2} \operatorname{sen}(\ln x)\,\frac{dx}{x} = \int_{0}^{\ln 2} \operatorname{sen} u\,du = [-\cos u]_{0}^{\ln 2} = 1 - \cos(\ln 2).$$
>
> **(m)** Descomponiendo en fracciones simples $\frac{4}{x(x+1)^{2}} = \frac{4}{x} - \frac{4}{x+1} - \frac{4}{(x+1)^{2}}$:
> $$\int \frac{4}{x^{3}+2x^{2}+x}\,dx = 4\ln|x| - 4\ln|x+1| + \frac{4}{x+1} + C = 4\ln\left|\frac{x}{x+1}\right| + \frac{4}{x+1} + C.$$
>
> **(n)** Descomponiendo en fracciones simples:
> $$\int \frac{1}{x^{2}-4}\,dx = \frac{1}{4}\int \left(\frac{1}{x-2} - \frac{1}{x+2}\right)dx = \frac{1}{4}\ln\left|\frac{x-2}{x+2}\right| + C.$$
>
> **(o)** Por partes ($u=x$, $dv=\operatorname{sen} x\,dx$):
> $$\int x\operatorname{sen} x\,dx = -x\cos x + \int \cos x\,dx = -x\cos x + \operatorname{sen} x + C.$$
>
> **(p)** Separando la suma en el numerador:
> $$\int \frac{3+4x}{x^{2}+1}\,dx = 3\int \frac{dx}{x^{2}+1} + 2\int \frac{2x}{x^{2}+1}\,dx = 3\arctan x + 2\ln(x^{2}+1) + C.$$
>
> **(q)** Aplicando integración por partes repetida:
> $$\int (x^{2}-2x+5)e^{-x}\,dx = -(x^{2}+5)e^{-x} + C \implies \int_{1}^{2}(x^{2}-2x+5)e^{-x}\,dx = \left[-(x^{2}+5)e^{-x}\right]_{1}^{2} = \frac{6e-9}{e^{2}}.$$
>
> **(r)** Por partes ($u=(\ln x)^{2}$, $dv=dx$):
> $$\int (\ln x)^{2}\,dx = x(\ln x)^{2} - 2\int \ln x\,dx = x(\ln x)^{2} - 2x\ln x + 2x + C.$$
>
> **(s)** Por partes ($u=\arctan x$, $dv=x\,dx$):
> $$\int x\arctan x\,dx = \frac{x^{2}}{2}\arctan x - \frac{1}{2}\int \frac{x^{2}}{x^{2}+1}\,dx = \frac{x^{2}+1}{2}\arctan x - \frac{x}{2} + C.$$
>
> **(t)** Inmediata tipo logaritmo:
> $$\int \frac{2x}{x^{2}+1}\,dx = \ln(x^{2}+1) + C.$$
>
> **(u)** Por propiedades de logaritmos y partes:
> $$\int \ln\frac{x^{2}}{9}\,dx = \int (2\ln x - \ln 9)\,dx = 2(x\ln x - x) - x\ln 9 + C = x\ln\left(\frac{x^{2}}{9}\right) - 2x + C.$$
>
> **(v)** Por partes ($u=x$, $dv=e^{x}\,dx$):
> $$\int x e^{x}\,dx = (x-1)e^{x} + C.$$
>
> **(w)** Por fracciones simples $\frac{x+3}{x(x+1)} = \frac{3}{x} - \frac{2}{x+1}$:
> $$\int \frac{x+3}{x^{2}+x}\,dx = 3\ln|x| - 2\ln|x+1| + C.$$
>
> **(x)** Por partes dos veces:
> $$\int x^{2} e^{x}\,dx = (x^{2} - 2x + 2)e^{x} + C.$$
>
> **(y)** Simplificando la fracción:
> $$\int \frac{x^{3}+x}{x^{2}+1}\,dx = \int \frac{x(x^{2}+1)}{x^{2}+1}\,dx = \int x\,dx = \frac{x^{2}}{2} + C.$$
>
> **(z)** Dividiendo los polinomios:
> $$\int \frac{2x^{3}}{x^{2}-1}\,dx = \int \left(2x + \frac{2x}{x^{2}-1}\right)dx = x^{2} + \ln|x^{2}-1| + C.$$

> [!success] Solución del Ejercicio 2
> **(a)** Dado que $e^{-x} > 0$ en todo $\mathbb{R}$:
> $$\text{Área} = \int_{-3}^{1} e^{-x}\,dx = \left[-e^{-x}\right]_{-3}^{1} = -e^{-1} - (-e^{3}) = e^{3} - \frac{1}{e}.$$
>
> **(b)** $f(x) = \cos 2x$ cambia de signo en $x = \frac{\pi}{4}$ y $x = \frac{3\pi}{4}$ dentro de $[0,\pi]$:
> $$\text{Área} = \int_{0}^{\pi/4} \cos 2x\,dx - \int_{\pi/4}^{3\pi/4} \cos 2x\,dx + \int_{3\pi/4}^{\pi} \cos 2x\,dx = \frac{1}{2} - (-1) + \frac{1}{2} = 2.$$
>
> **(c)** $f(x) = x^{2}-4x+3 = (x-1)(x-3)$ se anula en $x=1$ dentro de $[0,2]$:
> $$\text{Área} = \int_{0}^{1} (x^{2}-4x+3)\,dx - \int_{1}^{2} (x^{2}-4x+3)\,dx = \frac{4}{3} - \left(-\frac{2}{3}\right) = 2.$$
>
> **(d)** Factorizando $f(x) = (x-1)(x-3)(x-4)$, se anula en $x=1, 3, 4$ dentro de $[-1,4]$:
> - En $[-1,1]$, $f(x) \le 0 \implies \text{Área}_{1} = \left|\int_{-1}^{1} f(x)\,dx\right| = \left|-\frac{88}{3}\right| = \frac{88}{3}.$
> - En $[1,3]$, $f(x) \ge 0 \implies \text{Área}_{2} = \int_{1}^{3} f(x)\,dx = \frac{8}{3}.$
> - En $[3,4]$, $f(x) \le 0 \implies \text{Área}_{3} = \left|\int_{3}^{4} f(x)\,dx\right| = \left|-\frac{5}{12}\right| = \frac{5}{12}.$
>
> Sumando las regiones:
> $$\text{Área} = \frac{88}{3} + \frac{8}{3} + \frac{5}{12} = \frac{389}{12}.$$

> [!success] Solución del Ejercicio 3
> Aplicando el teorema de Fubini:
> $$\iint_{R}(x+2y)\,dA=\int_{0}^{1}\!\!\int_{0}^{1}(x+2y)\,dy\,dx=\int_{0}^{1}\left[xy+y^{2}\right]_{y=0}^{1}dx=\int_{0}^{1}(x+1)\,dx=\left[\frac{x^{2}}{2}+x\right]_{0}^{1}=\frac{3}{2}.$$

> [!success] Solución del Ejercicio 4
> Separando en dos integrales inmediatas:
> $$\iint_{R}xy(x+y)\,dA=\int_{0}^{1}\!\!\int_{0}^{1}\left(x^{2}y+xy^{2}\right)dy\,dx=\frac{1}{6}+\frac{1}{6}=\frac{1}{3}.$$

> [!success] Solución del Ejercicio 5
> El integrando es producto de una función de $x$ por otra de $y$, luego la integral doble factoriza:
> $$\iint_{R}\frac{x^{2}}{1+y^{2}}\,dA=\left(\int_{0}^{1}x^{2}dx\right)\left(\int_{0}^{1}\frac{dy}{1+y^{2}}\right)=\frac{1}{3}\cdot\frac{\pi}{4}=\frac{\pi}{12}.$$

> [!success] Solución del Ejercicio 6
> Integrando primero en $y$:
> $$\int_{1}^{2}\frac{dy}{(x+y)^{2}}=\left[-\frac{1}{x+y}\right]_{y=1}^{2}=\frac{1}{x+1}-\frac{1}{x+2},$$
> luego
> $$\iint_{R}\frac{1}{(x+y)^{2}}\,dA=\int_{3}^{4}\left(\frac{1}{x+1}-\frac{1}{x+2}\right)dx=\ln\frac{5}{4}-\ln\frac{6}{5}=\ln\frac{25}{24}.$$

> [!success] Solución del Ejercicio 7
> La integral factoriza:
> $$\iint_{R}\frac{1}{\sqrt{x}}\,dA=\left(\int_{0}^{1}x^{-1/2}dx\right)\left(\int_{0}^{1}dy\right)=\left[2\sqrt{x}\right]_{0}^{1}\cdot 1=2.$$

> [!success] Solución del Ejercicio 8
> De nuevo factoriza:
> $$\iint_{R}xy\,dA=\left(\int_{0}^{2}x\,dx\right)\left(\int_{1}^{3}y\,dy\right)=\left[\frac{x^{2}}{2}\right]_{0}^{2}\cdot\left[\frac{y^{2}}{2}\right]_{1}^{3}=2\cdot 4=8.$$

> [!success] Solución del Ejercicio 9
> $$\iint_{R}(x^{2}+2y)\,dA=\int_{0}^{2}\!\!\int_{0}^{1}(x^{2}+2y)\,dy\,dx=\int_{0}^{2}\left(x^{2}+1\right)dx=\left[\frac{x^{3}}{3}+x\right]_{0}^{2}=\frac{8}{3}+2=\frac{14}{3}.$$

> [!success] Solución del Ejercicio 10
> La región es de Tipo I con $1\le x\le 2$ y $x\le y\le 2x$:
> $$\int_{x}^{2x}\frac{dy}{(x+y)^{2}}=\left[-\frac{1}{x+y}\right]_{y=x}^{2x}=\frac{1}{2x}-\frac{1}{3x}=\frac{1}{6x},$$
> y por tanto
> $$\iint_{R}\frac{1}{(x+y)^{2}}\,dA=\int_{1}^{2}\frac{dx}{6x}=\frac{\ln 2}{6}.$$

> [!success] Solución del Ejercicio 11
> La región es de Tipo II: $0\le y\le 3$, $0\le x\le y^{2}$. Integrando primero en $x$:
> $$\int_{0}^{y^{2}}\left(2xy^{2}+2y\cos x\right)dx=\left[x^{2}y^{2}+2y\operatorname{sen} x\right]_{0}^{y^{2}}=y^{6}+2y\operatorname{sen}\left(y^{2}\right),$$
> luego
> $$\iint_{R}\left(2xy^{2}+2y\cos x\right)dA=\int_{0}^{3}\left(y^{6}+2y\operatorname{sen}\left(y^{2}\right)\right)dy=\frac{3^{7}}{7}-\cos 9+1=\frac{2194}{7}-\cos 9.$$

> [!success] Solución del Ejercicio 12
> La región es de Tipo II ($-6\le y\le 2$), así que integramos primero en $x$:
> $$\int_{y^{2}/4-1}^{2-y}x\,dx=\frac{1}{2}\left[(2-y)^{2}-\left(\frac{y^{2}}{4}-1\right)^{2}\right],$$
> e integrando en $y$:
> $$\iint_{R}x\,dA=\frac{1}{2}\int_{-6}^{2}\left[(2-y)^{2}-\left(\frac{y^{2}}{4}-1\right)^{2}\right]dy=\frac{256}{5}.$$

> [!success] Solución del Ejercicio 13
> En polares la región es $0\le r\le 3$, $0\le\theta\le\pi$, con $dA=r\,dr\,d\theta$:
> $$\iint_{R}(x+y)\,dA=\int_{0}^{\pi}\!\!\int_{0}^{3}r(\cos\theta+\operatorname{sen}\theta)\,r\,dr\,d\theta=\left[\frac{r^{3}}{3}\right]_{0}^{3}\int_{0}^{\pi}(\cos\theta+\operatorname{sen}\theta)\,d\theta.$$
> El término del coseno se anula por simetría y $\int_{0}^{\pi}\operatorname{sen}\theta\,d\theta=2$, luego
> $$\iint_{R}(x+y)\,dA=9\cdot 2=18.$$

> [!success] Solución del Ejercicio 14
> Completando cuadrados, $x^{2}+y^{2}\le 4y\iff x^{2}+(y-2)^{2}\le 4$: es el disco de centro $(0,2)$ y radio $2$, contenido íntegramente en el semiplano $y\ge 0$. Por tanto la condición $y\ge 0$ no recorta nada y el área es la del disco completo:
> $$\iint_{R}dA=\pi\cdot 2^{2}=4\pi.$$

> [!success] Solución del Ejercicio 15
> Con el cambio $u=xy$, $v=\dfrac{y}{x}$ el recinto pasa a ser el rectángulo $1\le u\le 2$, $1\le v\le 4$. Despejando, $x=\sqrt{u/v}$, $y=\sqrt{uv}$, y el jacobiano vale
> $$\left|\frac{\partial(x,y)}{\partial(u,v)}\right|=\frac{1}{2v}.$$
> Como $x^{2}y^{2}=u^{2}$:
> $$\iint_{R}x^{2}y^{2}\,dA=\left(\int_{1}^{2}u^{2}du\right)\left(\int_{1}^{4}\frac{dv}{2v}\right)=\frac{7}{3}\cdot\frac{\ln 4}{2}=\frac{7\ln 2}{3}.$$

> [!success] Solución del Ejercicio 16
> El recinto es el cuarto de disco unidad del primer cuadrante: $0\le r\le 1$, $0\le\theta\le \frac{\pi}{2}$. Con $dA=r\,dr\,d\theta$:
> $$\iint_{R}\sqrt{1-x^{2}-y^{2}}\,dA=\int_{0}^{\pi/2}\!\!\int_{0}^{1}\sqrt{1-r^{2}}\,r\,dr\,d\theta=\frac{\pi}{2}\left[-\frac{(1-r^{2})^{3/2}}{3}\right]_{0}^{1}=\frac{\pi}{2}\cdot\frac{1}{3}=\frac{\pi}{6}.$$

> [!success] Solución del Ejercicio 17
> **(a) Tipo I (vertical):** Para $0 \le x \le 2$, la variable $y$ va de $0$ a la recta $y=x$:
> $$\iint_{\Omega} xy\,dA = \int_{0}^{2}\!\!\int_{0}^{x} xy\,dy\,dx.$$
>
> **(b) Tipo II (horizontal):** Para $0 \le y \le 2$, la variable $x$ va de la recta $x=y$ hasta $x=2$:
> $$\iint_{\Omega} xy\,dA = \int_{0}^{2}\!\!\int_{y}^{2} xy\,dx\,dy.$$

> [!success] Solución del Ejercicio 18
> **(a)** El recinto de integración es el triángulo de vértices $(0,0)$, $(1,1)$ y $(0,1)$, delimitado por $0 \le x \le 1$ y $x \le y \le 1$.
>
> **(b)** Cambiando el orden a Tipo II ($0 \le y \le 1$, $0 \le x \le y$):
> $$\int_{0}^{1}\!\!\int_{0}^{y} e^{y^{2}}\,dx\,dy.$$
>
> **(c)** Resolviendo la integral:
> $$\int_{0}^{1}\!\!\int_{0}^{y} e^{y^{2}}\,dx\,dy = \int_{0}^{1} y e^{y^{2}}\,dy = \left[\frac{e^{y^{2}}}{2}\right]_{0}^{1} = \frac{e-1}{2}.$$

> El recinto es el triángulo $0\le y\le x\le 1$. Integrando primero en $y$ (que es lo que hace calculable la integral):
> $$\iint_{R}e^{x^{2}}dA=\int_{0}^{1}\!\!\int_{0}^{x}e^{x^{2}}\,dy\,dx=\int_{0}^{1}x e^{x^{2}}dx=\left[\frac{e^{x^{2}}}{2}\right]_{0}^{1}=\frac{e-1}{2}.$$
